# MON-PROJET
Dans le cadre de l'évaluation de fin de module sur le developpement web statique,nous avons réaliser un site vitrine de restaurant de cuisine africaine basé à Dakar.
## Sujet A _Restaurant
Un nouveau restaurant de cuisine africaine moderne souhaite un site vitrine elegant et responsif pour présenter son consept, son menu et permettre aux clients de le contacter .
## Technologie utilisées 
-HTML5        Structure semantique des pages
-CSS3         Styles personnalisés et animation 
-Bootsrap 5        Grille responsive et composants UI  
-Bootsrap Icons    Icones de l'interface
JavaScript         Interactive et validations 
Netlify             Depoliement en ligne

## Fonctionnalités
Validation formulaire avec le fichier script.js : Champs obligatoires + format email
Filtre dynamique menu avec le fichier script.js : Affiche/masque les plats par catégorie
Carousel Bootsrap avec le fichier index.html : Defilement automatique des plats signature
Bouton retour en haut avec le fichier script.js : Apparait dans chaque page
